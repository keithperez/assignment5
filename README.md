# COMP590 - Assignment 5 / Shader Graphs

All files are in the GitHub repo for the first time in a while!

This shader is just a simple lightsaber shader with support for two blades like Darth Maul's, but also has support for impact frames!
By setting WobbleSpeed to 0 in the Lightsaber blader material, it makes so that everything on screen turns white, while the blades themselves
turn black. It looks cool but...
